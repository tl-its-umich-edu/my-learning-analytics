## Accessibility

### Keyboard Navigation

Users that use Safari or Firefox on macOS that would like to enable keyboard navigation in MyLA
will have to follow the steps [here](https://github.com/tl-its-umich-edu/my-learning-analytics/wiki/Project:-Accessibility).

Closing the navigation drawer with Escape or the backdrop returns focus to Menu.
Choosing a drawer link focuses the destination heading after the drawer finishes
closing. View headings remain programmatically focusable without entering the Tab order.
